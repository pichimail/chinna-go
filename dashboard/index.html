Welcome to Chinna on Mac

A dedicated quick start for first-time users
A Mac app feel from the first launch
Pick the macOS theme, install the native app wrapper, and add SwiftBar quick actions in one pass.
1
Install Chinna.app
Create the branded app bundle in Applications for Dock, Spotlight, and native-style launching.
2
Add SwiftBar actions
Put Purge, Clean, Update, and dashboard actions in the menu bar near the notch.
3
Use the macOS theme
Switch to the glassy macOS look for the dashboard, built for a lighter and more native feel.
4
Continue to tools
Open macOS Tools, then move into the rest of the dashboard once setup is complete.
What you get
• Real Chinna.app wrapper with branded icon
• Menu-bar quick actions for the notch / SwiftBar
• macOS theme that stays selected for this device
• One-click launch path for new users
First-time users should start here. Existing users can skip directly into the tools.
